# Contributing

Xayra is proprietary software maintained by one person. External
contributions are not being sought at the moment.

- **Pull requests:** unsolicited pull requests will usually be closed without
  review. Please don't spend time preparing one.
- **Bugs and suggestions:** you're welcome to open an issue. Don't include
  your own notes, recordings, transcripts, to-dos or other personal data.
- **Security problems:** don't open a public issue. Report them privately as
  described in [SECURITY.md](SECURITY.md).

Opening an issue or pull request doesn't grant you or anyone else any right
to use, copy, modify or distribute Xayra's code (see [LICENSE](LICENSE)). The
maintainer may still use ideas raised in an issue.
